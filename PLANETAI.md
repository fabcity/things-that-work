# Things That Work — the response layer of PLANETAI

**Canonical positioning.** Things That Work (TTW, `ttw.fab.city`) is the
**response-template library of PLANETAI** — the catalogue the network draws from
when an observation triggers a fabrication response. This is not a loose
association; it maps onto a named component of the PLANETAI architecture.

## Where it sits in the stack

PLANETAI is Fab City's instrument for *closing the loop between Earth observation
and community-scale response* — community-scale sensing → bioregional decision →
distributed fabrication response, in **days-to-months, not years-to-decades**.

Its five-tier stack names, at **Tier 02 (Bioregion) — the decision tier** — an
**"OSH/OKH response-template library"** alongside the partner-hosted servers,
knowledge graphs, and the community-council veto. That library is the slot. **TTW
is what fills it, made human:** an open, trilingual, offline-first repository of
solutions that work when services fail — 1,500+ entries across eight traditions
(Whole Earth Catalog, Cuban technological disobedience, Japan's OLIVE disaster
wiki, Appropedia, MSF, Field Ready, Ferulas Venezuela, and the household manuals).

## How the response layer uses it

- **The four action agents draft from it.** A1·Bali, A2·Barcelona, A3·Santiago,
  A4·Boston are narrow, human-in-the-loop agents that *draft, never dispatch*.
  A2 Barcelona is specified to run its waste-to-production loop **against the
  OSH/OKH library** — that library is TTW.
- **It is the `fabricate` step.** PLANETAI's action cycle has five timestamped
  stages: **detect → decide → fabricate → deploy → measure**. An agent can detect
  and decide, but the *fabricate* step needs a catalogue of what is actually
  buildable, locally, by people. That catalogue is TTW.
- **It gives ρ something to act with.** The Fab City Index 3.0 score is
  **FCI = DIDO · (1 − PITO) · ρ**, where **ρ (action latency)** is the speed at
  which an observation produces a fitted, human-approved response. A response
  library is the precondition for ρ > 0 — you cannot close the loop fast if there
  is nothing vetted to build. TTW is where the network's response time is won or
  lost, and it is the substrate behind hypothesis **H0-A** (action-latency).

## Venezuela is the first live instance

The `/venezuela` response surface is the response layer running for real: a
compound crisis (the June 2026 Morón earthquake atop years of degraded services),
the archive filtered by failure-mode ("Del archivo — según lo que falla"), a live
3D-printing response (Ferulas splints, Field Ready medical parts), and a
participatory loop (report, contribute, makers). It is what the PLANETAI response
tier looks like when it touches the ground.

## Honesty about maturity

This is canonical *positioning*, stated so the relationship is unambiguous and
durable. The PLANETAI pilots themselves are **v0**: MoUs largely "Not Started" and
much pilot data still synthetic during the prototype window (per the Fab City
Metrics backend). TTW is real and growing; its formal wiring into each pilot's
node (the federated-data box, the agent draft→approve→deploy ledger) is the work
ahead, not a finished fact.
